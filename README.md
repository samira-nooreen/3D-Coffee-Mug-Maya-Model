# Coffee Mug – Maya 3D Model

This repository features a 3D modeled coffee mug that I created using Autodesk Maya.  
It is a simple but clean household prop asset that can be used in interior design, kitchen scenes, or small animation projects.

---

### 🛠️ Software Used
- Autodesk Maya

### 📂 Files Included
- `mug.mb` – Maya project file (editable mesh)

---

### ✔️ Model Features
- Smooth subdivision-ready mesh
- Realistic proportions with a well-shaped handle
- Clean topology suitable for:
  - Rendering
  - Interior visualization
  - Game environment props
